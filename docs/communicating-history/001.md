### 📦 项目全景

**核心——无感自动记账的实现路径：**

| 渠道 | 方式 | 状态 |
|---|---|---|
| **Android 无障碍服务** | 支付成功后自动读取屏幕上的金额和商户 | 已实现（`android/` 目录） |
| **剪贴板监听** | Web 端监听剪贴板，检测到支付信息自动识别 | 已实现（设置中开启） |
| **CSV 导入** | 支付宝/微信账单文件一键导入 | 已实现 |
| 通知栏解析 | 解析支付通知文本 | 框架已就绪 |

**Android 无障碍服务的自动记账流程：**
```
付款 → 支付成功页面出现 → AccessibilityService 检测 → 
遍历节点树提取金额+商户 → Broadcast 发送 → 
TransactionReceiver 接收 → 存入本地文件 → WebView 自动刷新
```

**Web 端功能模块：**
- **仪表板** — 今日/本月/年度统计、每日支出趋势柱状图、分类饼图、预算进度条
- **交易记录** — 列表、搜索、筛选（类型/月份）、编辑/删除
- **分类管理** — 13 种默认分类 + 自定义图标和颜色
- **预算管理** — 按分类设置月度预算，超支预警
- **导入账单** — 上传支付宝/微信 CSV，自动解析预览
- **设置** — 剪贴板监听开关、数据导出、清理

**技术细节：**
- 纯本地存储（IndexedDB），无网络依赖，无隐私风险
- Tailwind CSS 响应式布局，支持移动端和桌面端
- Recharts 图表、Lucide 图标
- Android 原生模块用 Java 编写（无障碍服务 + 广播接收器）

### 📦 一键构建

在安装了 **JDK 17+** 和 **Android SDK** 的电脑上：

```bash
# 方式一：双击运行
build-apk.bat

# 方式二：命令行
npm run build-apk
```

脚本会自动完成 5 步：
1. 检测 Java 环境（缺失则尝试自动安装）
2. 定位 Android SDK，生成 `local.properties`
3. `npm run build` → `npx cap sync` 同步 Web 资源
4. `gradlew assembleDebug` 编译 Android
5. 复制并重命名为 **`无感化记账-第一版.apk`**
