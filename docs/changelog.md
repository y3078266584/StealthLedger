# 变更日志 Changelog

## v1.1.2 (2026-06-13) — 通用支付检测

- **架构重构**: 移除 AccessibilityService 包名白名单 → 任意 APP 支付页面均可捕获
- **通知监听升级**: 移除支付宝/微信包名过滤 → 所有 ¥/￥ 通知均检测
- **去重升级**: 复合键 pp + amount + merchant 替代旧的时间+平台
- 修复: 剪贴板监听服务状态检查

- 新增: 设置页系统权限控制（自启动、后台活动）
- 新增: 小米/Huawei/OPPO/VIVO/三星/魅族 ROM 适配
